# R8 keep rules for RELEASE AAB builds (owner decision 2026-11-12: minify on so Play Console gets a mapping file).
# Used only when PlayerSettings "Minify > Release" and "Custom Proguard File" are on; AndroidReleaseBuild switches both on for the release path and back off afterwards.
# Unity adds its own rules (proguard-unity.txt: com.unity3d.player.*, bitter.jnibridge, fmod, GameActivity) on top of this file; they are not repeated here.
# Most SDK AARs carry consumer rules that R8 applies automatically; the rules below are belt and braces for classes that C# reaches by name through JNI (AndroidJavaObject / AndroidJavaProxy)
# or by reflection, which R8 cannot see. Rules for libraries that are not in the build match nothing and are harmless.

# ---- readable crash traces (the mapping file restores names; keep line numbers) ----
-keepattributes Signature,InnerClasses,EnclosingMethod,Exceptions,*Annotation*,SourceFile,LineNumberTable
# (-renamesourcefileattribute is a global option; Android Gradle rejects it in this consumer rules file: Gradle error on the 2026-11-12 trial build)
