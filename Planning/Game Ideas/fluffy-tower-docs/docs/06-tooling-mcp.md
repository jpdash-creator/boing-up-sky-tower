# 06 - Tooling: What to Hook to Claude (MCP) vs. Code Directly

Short answer: **write the game in Unity C# (code directly), and hook MCP servers only for the things Claude cannot do from files alone**: driving the Unity Editor, generating images, reading designs, testing, and managing the backend. Claude Code already edits files, runs builds from the shell and uses git, so most work needs no MCP.

## 1. Recommended setup

| Need | Tool | MCP or direct? | Why |
|---|---|---|---|
| Game code (C#) | Claude Code editing the Unity project | Direct | Plain files |
| Control the Unity Editor (create scenes, prefabs, import settings, run tests, read console, build) | A community **Unity MCP** server (e.g. CoplayDev/unity-mcp, IvanMurzak/Unity-MCP) **(verify which is maintained and compatible with Unity 6)** | MCP | Lets Claude see the console, create assets and run PlayMode tests without you copy-pasting |
| Image generation | **OpenArt MCP** (already connected in this session) or another image-model MCP | MCP | Core of the asset factory; can run seeded batches and track creations |
| Image post-processing (trim, bg-remove, slice, pack, mirror, palette check) | Python scripts (Pillow, rembg, OpenCV) run by Claude via shell | Direct | Deterministic and scriptable; no MCP needed |
| Sprite atlas / sheet packing | TexturePacker CLI or Unity Sprite Atlas | Direct (CLI) | |
| UI mockups and design hand-off | **Figma MCP** (needs authorization) | MCP | Pull layouts/tokens into Unity UI Toolkit |
| Backend admin (PlayFab) | PlayFab Admin REST API via scripts / a small CLI | Direct (scripts) | Title data and catalog upload from CI. A PlayFab MCP is optional **(verify availability)** |
| Store consoles | fastlane (supply/deliver), `gh`, Google Play Developer API | Direct (CLI) | Store metadata and builds. MCP not needed |

### OpenArt credit guardrail
OpenArt is a **paid Plus plan**. Every credit-consuming call (`openart_generate_image`, `openart_generate_video`, edits, upscales) needs the owner's explicit approval of the exact batch, with an approval packet (purpose, tool, model and settings, full prompts, per-job and total credits, balance after, alternatives). Read-only tools (account, model list/cost/form, creation list) are free. Rule file: `.claude/rules/openart-credit-guardrail.md`; every job is logged in `Content/assets/assets_log.csv`.

## 2. Platform realities you must plan for
- **iOS build and submission require macOS + Xcode.** Options: a Mac mini, cloud Mac (MacStadium, AWS EC2 Mac), or Unity Build Automation / GitHub Actions macOS runners. Your current machine is Windows 11, so Android can be built locally; iOS needs one of these.
- You need an Apple Developer account and a Google Play developer account (see doc 05).
- Unity needs a licence (Personal is free under the revenue threshold **(verify current terms)**).

## 3. Suggested Claude workflow
1. Claude Code opens the Unity project folder; a `CLAUDE.md` file documents architecture and conventions (copy from docs 03-04).
2. Unity MCP lets Claude create the scene skeleton, wire prefabs, and run tests.
3. OpenArt MCP + Python post-processing scripts generate and normalize art in batches, writing results into `Art/` and the catalog JSON.
4. CI (GitHub Actions) validates content, runs the bot, builds AAB (Android) and IPA (iOS via macOS runner), and uploads to TestFlight/Play internal track.
5. Claude produces weekly content drops: generate assets -> create defs -> validate -> publish to CDN.

## 4. Custom tools to build (small, high leverage)
- **Content CLI** (`content validate | build | publish`): validates JSON against schemas, builds Addressable bundles, uploads to CDN and PlayFab.
- **Asset normalizer** (Python): alpha trim, pivot, palette check, template-overlap check, preview render.
- **Level bot**: headless sim player used for solvability and difficulty estimates.
- **Catalog sheet**: spreadsheet of all items/regions/prices as the single source of truth, exported to JSON.
- **Back-office**: minimal web page (or just the content CLI) for offers and events.

## 5. Skills/agents inside Claude Code
Keep small project skills: `add-region`, `add-item`, `generate-asset`, `publish-content`, `release-build`. Each skill is a checklist that calls the CLI tools above, which makes the weekly content cadence nearly one command.
